Run your conference from the terminal.

The command-line surface for Konf. Review talk proposals, manage the sponsor pipeline, and run your conference via a first-class programmatic surface.

$ brew tap RunKonf/tap $ brew install konf ==> Downloading https://github.com/RunKonf/konfctl/releases/download/... ==> Installing konf $ konf login Opening browser to authenticate...
Installation

Get konf on your machine

Homebrew (macOS / Linux) brew tap RunKonf/tap
brew install konf
Direct Download Grab the latest prebuilt binary for your platform from GitHub Releases. Every release includes a Sigstore attestation for verifiable supply-chain security.
Build from source git clone https://github.com/RunKonf/konfctl.git
cd konfctl && cargo install --path .
Usage

Fast, interactive, and scriptable

konf is designed for organizers at a terminal, and LLM agents acting on their behalf.

bash
# Login to your conference konf login # Interactive fuzzy-search for proposals konf admin proposals list # Filter and output as JSON for scripting konf admin proposals list --status accepted --json | jq '.[].title' # Agent-native mode for Claude/Cursor/Gemini (protected by AGENT_GUARD_BLOCK safety guards) konf --agent admin sponsors list
