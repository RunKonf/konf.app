What running a conference on Konf looks like

The screenshots below come from KontainerKonf, our demo conference. Every feature here runs Cloud Native Days Norway today, unless it carries a soon badge.

CfP and speakers

From call for papers to confirmed speakers

Speakers submit on your site. Your team reviews and rates every proposal in one place, then accepts or declines. Accepted speakers get an email and a notification, and confirm their talk themselves.

  • Co-speakers, messaging and travel support
  • Reminders to confirm, upload slides and finish travel claims
# review from the terminal
konf admin proposals list --status submitted --sort rating
konf admin proposals review <id> --content 4 --relevance 3 --speaker 5
Program and schedule

Drag talks into the schedule

Accepted talks are ready to place. Drag them across tracks and time slots, and the public program updates. When a talk moves, its speakers get a push notification.

  • Several tracks and days
  • Workshops with capacity and signup windows
  • Now-and-next screens for each room
query Program {
  program {
    days {
      date
      slots { start end room talk { title speakers { name } } }
    }
  }
}
Sponsors

A sponsor pipeline instead of a spreadsheet

Track each sponsor from first contact to signed contract. Contracts are generated and e-signed in Konf. When a contract is signed, the logo goes on your front page and the invoice lands on the follow-up list.

  • Tiers, activity timeline and action items
  • Ticket allocations for sponsors through discount codes
query Sponsors {
  sponsors {
    tier { name level }
    sponsor { name website logoUrl }
  }
}
Tickets

Sell tickets with the provider you already use

Connect Checkin or Tito. Ticket sales feed the conference budget, so you see income from tickets and sponsors against your target without exporting anything.

  • Discount codes with usage tracking
  • Budget with expenses and scenarios
# sales, participants, complimentary seats
konf admin tickets stats
konf admin tickets stats --json | jq .

Speakers keep one profile across every conference on Konf: bio, photo, talk history and signed Open Badges. Your CfP starts pre-filled, and you can find speakers who have spoken at other community events. Signed badges are live today; the shared profile and directory are being built.

One GraphQL API

API first

Every part of Konf runs on one GraphQL API at api.konf.app. The public conference site and the control panel, Kontroll at my.konf.app, are both clients of that same API. Nothing sits behind an internal-only backend. Today the API is used by our own site, by Kontroll and by signed-in organizers in the explorer; API clients for your own integrations are next.

What's next: API clients and tokens you create yourself, webhooks, a hosted MCP server, a connect-your-domain flow and self-serve sign-up.

The alternative

You could assemble it yourself. We did, once.

Every community conference ends up building the same duct-tape stack: a CFP tool here, a website builder there, ticketing embedded from somewhere else, sponsors in a spreadsheet, contracts in a PDF tool, updates in a newsletter product. Six subscriptions, six logins, and none of them talk to each other.

git diff — your-conference/stack
@@ tools required to run one community conference @@ cfp-and-review-tool # per-event fee, data lives there website-builder # fights you on schedule layouts ticketing-embed # iframe, own branding, own login sponsor-spreadsheet # "who signed? check the email thread" e-signature-subscription # for four contracts a year newsletter-tool # speakers marked as spam konf # one platform, pieces that talk

The value is the glue. Accept a talk in Konf and the speaker gets the email and the in-app notification, while the talk drops straight into the schedule builder ready to place — no re-keying, no CSV export. Countersign a sponsor contract and the deal moves to closed-won, the logo lands on the front page, and the invoice shows up on the follow-up list. Integrated beats assembled, and it's priced for community budgets: one yearly price per organization, not six SaaS subscriptions deep.

The network

Better together, as the network grows

Every conference on Konf strengthens the others. These are the network benefits we're building toward for conferences that join early:

One speaker profile
Speakers keep a single profile across every Konf conference — bio, photo, talk history and signed badges follow them, so your CFP starts pre-filled instead of empty.
A verifiable track record
Signed Open Badges accumulate into a portable, cryptographically verifiable speaking CV — proof of every stage a speaker has stood on across the network.
Cross-promotion
Community events surface each other: attendees of one conference discover the next one in the network — opt-in, and never at your audience's expense.
Sponsor introductions
Sponsors who back one community conference are usually looking for the next one. The network makes those introductions instead of leaving them to chance.
Organizer commons
Playbooks, benchmarks and a backchannel with people who have run the same sprint — because every organizing team hits the same walls in the same order.

FAQ

Questions organizers ask

Why invite only?

We onboard a few conferences at a time and help each one set up. Self-serve sign-up opens once that process is smooth.

Is it really free for free events?

Yes. If nobody pays to attend, you get the whole platform and no invoice.

How does billing work?

Paid plans are billed once a year, per organization. There is no monthly option and no cut of ticket sales. You pay when your site goes live, not while you set it up.

Can we use our own domain?

Every conference gets a <name>.konf.run address. Paid plans can use their own domain.

Which ticketing providers work?

Checkin and Tito today. Konf reads ticket sales from them; attendees buy tickets through the provider.

Who runs Konf?

The team behind Cloud Native Days Norway in Bergen. Konf runs that conference every year.

Can we get our data out?

Everything is available through the same GraphQL API that the site and the control panel use.
